# The Veil of Night — Playtest

**The Veil of Night: Beneath the Silence** is a supernatural investigation
game. You lead a team of four investigators through haunted cases: search
painted rooms for clues, question witnesses, piece the evidence together in
your casebook, and face what's behind it in turn-based combat. Between cases,
the team recovers, trains and talks things over at their headquarters.

This repository holds **playtest builds only**. It's an unfinished game, and
your feedback shapes it.

## Download (Windows)

**[Get the latest playtest →](https://github.com/Tallsam20/veil-playtest/releases/latest)**

Under **Assets**, download the `Veil-of-Night-Windows-Playtest-….zip` file
(about 640 MB). It's for 64-bit Windows. The release page lists what's new in
each build.

## Install and play

1. Right-click the ZIP and choose **Extract All**. Don't run the game from
   inside the ZIP.
2. Open the extracted folder and double-click **VeilOfNight.exe**. Keep
   `VeilOfNight.pck` in the same folder.
3. Windows may show **"Windows protected your PC"**, because the game isn't
   code-signed yet. Click **More info**, then **Run anyway**.
4. Start a new campaign. Nothing else needs to be installed.

**Finding your way:** the lead in the side panel always names your next
step. *How to play* and *Replay world introduction* are on the title screen.

**Controls:**
- **Click** gold markers to approach and investigate.
- **1–4** pick an investigator.
- **J** casebook, **M** field map, **E** talk to someone nearby, **B** case
  brief.
- In combat, **Space** ends a turn and **T** shows the threat forecast.
- **F5** save, **F9** load, **Esc** settings.

Saves are kept in Windows' app data folder, so deleting the game folder
doesn't delete them.

## Content note

The game contains supernatural horror, grief, cult activity, violence,
spiritual corruption, obsession, despair and existential dread.

## Feedback

Tell us:
- where you stopped;
- what was fun and what dragged;
- where you didn't know what to do;
- anything that broke.

For a bug, the most useful details are the room, the investigator, what you
did, what you expected and what happened, plus a screenshot if you can.
Roughly how long you played helps too.

You can [open an issue here](https://github.com/Tallsam20/veil-playtest/issues)
(this needs a free GitHub account; issues are public), or send your notes to
whoever shared the game with you.

## Fine print

These are unsigned development builds. They haven't been tested on every
Windows graphics driver yet. If the game won't start, an issue with your
Windows version and graphics card is very helpful.
